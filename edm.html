Capstone Missions · 택 1 / 135분 목표

네 가지 정체성, 하나의 완주

난이도가 아니라 정체성이 다른 네 가지 미션입니다. 관심사에 맞춰 하나를 골라, 다섯 챕터의 근육을 전부 소환해 공개 URL 서비스를 배포합니다.

A

만드는 Claude — Ship It, 나의 Claude Ops Center를 배포하라

S3/CloudFront + API + Lambda + DynamoDB + Bedrock 질의 패널의 풀스택. 도구가 자기 자신을 관측하는 훅 루프.

미션 열기 →

B

지키는 Claude — Self-Heal, 무인 운영실을 세워라

장애 주입 → 헤드리스 메딕이 런북으로 감별 진단해 스스로 복구. PreToolUse 인터록으로 파괴 명령 차단.

미션 열기 →

C

파는 Claude — Grand Open, 말로 주문받는 AI 카페를 개점하라

자연어 주문을 Converse toolConfig로 구조화 추출, 주방 보드에 티켓이 실시간으로 흐른다.

미션 열기 →

D

기억하는 Claude — Grounded, 근거로만 답하는 사내 사서를 고용하라

Titan 임베딩 + DynamoDB 코사인 검색으로 RAG의 원리를 손으로. 근거 없으면 정직한 거절.

미션 열기 →

모든 캡스톤 마지막에는 OPTION 하네스 엔지니어링 (+15분) — project-init으로 표준 구조화, harness-eval로 6개 차원 등급 평가.
